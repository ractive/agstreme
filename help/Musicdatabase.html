What you need

In order to use the musicdatabase you need DAO 3.5 installed on your PC.
When you start AGStreme, there will be a message box that tells you if you don't have installed it. You can download it here:

http://www.ractive.ch/gpl/download/DAOInst.zip

Unpack this file and start "setup.exe" from the folder "Disk1".

Building and updating the database

AGStreme has a built in music database that allows easy organization of your music files.

Before you can use your database you have to build it. Start the wizard and choose "Update music database". You also have to do this if you add new files to your shared folders outside AGStreme.

In the second window you can choose from a couple of options to build the database:

 

These options massively determine how the database will be built. Experiment with different options and see if the result is ok. If not, delete the whole database (Menu "Database - Delete music database") and rebuild it with different options....

Filename format

First you have to choose a filename format. The filename format is like a mask that helps to identify informations from the filename. "<A> - <T>" is the normal audiogalaxy filename format.

The different format placeholders are as followed:

  • <A> Artist name
  • <T> Songtitle
  • <L> Album name
  • <N> Track on album

The normal audiogalaxy filename format "<A> - <T>" means "Artistname - Songtitle.mp3" though i.e. "Madonna - Like a virgin.mp3".

See the tooltip help for more information.

Directory options

If you organized your files in folders this may help to identify your files. I think this is quite self-explanatory, isn't it?

Importance order

This let you decide which information is more valuable. If your directory structure is well organized, you can increase the importance of the "Directroy structur information". If you have a lot of ID3 tags, you will put this importance to top.

Working with the database

As soon as you have built the database it's ready to use. Choose the "Music database" tab to show your music collection ordered by Artist/Album, genre and year:

 

If you click on an item in the tree, the "MP3 files" window will show the matching songs.

You can manage the database by drag and drop. If you want to i.e. add some songs to an album, drag the songs from the "MP3 files" window and drop them on the album they belong to. If the artist of a song is wrong, simply drag it on the correct artists name.

If the album or artist is not in the database yet, add the corresponding informations to the ID3 tag and update the database again.

 

You also can rename an item in the tree. The database is updated with the new value.

This way you can rapidly organize your music collection.
