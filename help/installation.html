Installation

Start the downloaded file "JAGS.exe". The installation program will start. I won't loose any word about this. It should be quite self-explanatory :-)

If you already installed the original AudioGalaxy satellite, you can install JAGS into the same directory. This way, you're settings will be re-used by JAGS.
