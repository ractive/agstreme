Preferences

To show the "Preferences" dialog, click on the button in the toolbar

Options

  • Keep log file:
    The satellite will create a log file (called logv606W.txt) of all transactions. This file may become really HUGE! Delete it from time to time if you don't need it any more.
    Generally, a log file is not needed...
  • Winamp: Enter (or search) the WinAmp program file
  • Organize: If you activate this option, JAGS will create separate subfolders for each artist and move the songs of this artists into it, if more than a defined value of songs (which you can enter) is available of the same artist. The name of the artist is currently only determined by the filename.

Account

Enter your username and password here.

You also can create a new account if desired.

Also useful if you forgot your password :-(

Proxy

Enter your proxy settings here. Only change these values if you know what you're doing!

Connection options

  • Bandwidth throttle: This allows you to define how much of your bandwidth should be used to transfer songs
  • Connection: Define what connection is available. These values are only used for the transfer-meter...
  • Simultaneous downloads: This value determines how many files are downloaded at the same time. If you have a fast connection, raise this value to use your bandwidth as good as possible.
